# VANTA — Contemporary Streetwear

**Nama: Putri Agita**  
**NIM: 535250020**

## Deskripsi
VANTA adalah website landing page single-page bertema contemporary streetwear. Website dibuat menggunakan Next.js, React, TypeScript, Bootstrap, dan CSS.

## Fitur
- Hero carousel dengan 3 slide, auto-play setiap 5 detik, serta tombol previous/next.
- Product carousel horizontal yang dapat di-scroll dan dikontrol dengan tombol.
- Active navbar menggunakan Intersection Observer (scroll-spy).
- Responsive navbar untuk tampilan mobile.
- Responsive layout menggunakan Bootstrap Grid dan CSS media queries.
- Section Home, Collection, Our Story, dan Contact.

## Cara Menjalankan
Pastikan Node.js sudah terpasang.

```bash
npm install
npm run dev
```

Buka http://localhost:3000 di browser.

## Build untuk production
```bash
npm run build
npm start
```

## Teknologi
- Next.js 14
- React 18
- TypeScript
- React Bootstrap / Bootstrap 5
- CSS3
